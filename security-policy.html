Security Policy | 安全政策

If you discover a security vulnerability in our website, please report it via GitHub Security Advisories. Do **not** submit it as a public GitHub Issue.

如果您在本站发现安全漏洞，请通过 GitHub Security Advisories 页面 反馈。请**不要**提交公开的 GitHub Issue。

Responsible Disclosure

We kindly ask that you do not publicly disclose any vulnerabilities until we have verified and resolved the issue.

在我们确认并修复问题之前，请勿公开披露任何漏洞信息。

Scope

This policy applies to all pages and services under the tiedan.site domain.

本政策适用于所有隶属于 tiedan.site 域名的网页和服务。

Contact

Please submit reports via GitHub Security Advisories or contact the site owner at tiedan0227@gmail.com.

您可以通过 GitHub Security Advisories 提交报告，或联系网站所有者：tiedan0227@gmail.com。

Thank You

We appreciate your efforts to help us maintain a safe and secure environment for all users.

感谢您为帮助我们维护安全、可靠的网站环境所作的努力。
